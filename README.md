## 📁 Estructura del Repositorio (Unidad 1)

Este repositorio está organizado en carpetas independientes para cada práctica y tarea evaluable de la unidad, garantizando la trazabilidad del historial y el orden en las entregas:

### 📂 1. Práctica 1: Fundamentos de Git Local
* **Descripción:** Introducción al control de versiones en el entorno local sin ramificaciones. Rastreo de archivos en el *Working Directory*, gestión del *Staging Area*, creación de confirmaciones (*commits*), uso de etiquetas (*tags*) y comandos para revertir o deshacer cambios.

### 📂 2. Práctica 2: Ramificación Local e Integración
* **Descripción:** Trabajo avanzado con ramas locales. Creación de líneas de desarrollo divergentes, fusión de ramas (*merge*) con resolución manual de conflictos, reorganización del historial (*rebase*), selección de commits específicos (*cherry-pick*) y corrección de commits en ramas incorrectas.
* **Estado:** 🏁 Finalizada.

### 📂 3. Tarea 1.6: Gestión de Tareas e Issues
* **Descripción:** Flujo de trabajo integrado con GitHub. Creación, asignación y categorización de incidencias mediante *labels* personalizados, y automatización del ciclo de vida de los *Issues* (cierre automático y manual) vinculados directamente a los mensajes de los *commits*.
* **Estado:** 🏁 Finalizada.
